# TarihTalks

Қазақстан тарихына арналған интерактивті платформа (5–11 сыныптар).

- `index.html` — негізгі платформа
- `lesson.html` — смарт тақтаға арналған сабақ режимі
- `data.js`, `causes.js` — мазмұн
- `assets/` — суреттер, видеолар
- `supabase/` — дерекқор баптаулары (SQL Editor-да ретімен іске қосылады)
